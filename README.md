# TriScan

TriScan is a desktop application for designing, simulating, and validating 3D scanning scenes. It focuses on active laser triangulation workflows, camera and device setup, calibration objects, timeline previews, and scene analysis.

This repository is the public distribution repository for TriScan installers and update metadata.

## Download

Use the latest GitHub Release to download the Windows installer:

[Download the latest TriScan release](https://github.com/PavelJanos/triscan-releases/releases/latest)

Current published version: `0.3.61`

This is the first broadly usable TriScan build, but it should still be treated as unstable.

## User Manual

## What TriScan Includes

- 3D workspace for scene construction and inspection
- Camera, laser, light, material, and primitive object tools
- Own model and calibrator catalogs
- Timeline and preview windows
- Calibration workflow support
- Bundled default data for a clean installation

## Repository Purpose

This repository is used for release distribution only:

- Windows installer assets
- updater metadata (`latest.yml`)
- user-facing documentation

Application source code is maintained separately in `triscan-source`.
